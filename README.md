## Hardware Specifications

The main control board used here is an [Arduino Uno rev 3](https://store-usa.arduino.cc/products/arduino-uno-rev3) with a [Motor Shield rRev3](https://store-usa.arduino.cc/products/arduino-motor-shield-rev3) attached. 

The grinder motor used is a [Pololu 70:1 Metal Gearmotor 37Dx54L mm 12V](https://www.pololu.com/product/4744/specs).
